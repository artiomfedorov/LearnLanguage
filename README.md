# Испанские тренажёры

Сайт: https://artiomfedorov.github.io/LearnLanguage/

- `index.html` — список всех тренажёров
- `trainer.html?set=<id>` — тренажёр одного набора (`?set=latest` — последний)
- `latest/` — постоянная ссылка на последнее задание
- `sets/index.json` — список наборов и `latest`
- `sets/<id>.txt` — слова набора

## Как добавить набор

1. Создать `sets/<id>.txt`, по строке на слово:
   `испанский|русский|ещё русские варианты;…|ещё испанские варианты;…|похожие слова=перевод;…`
2. Добавить запись в `sets/index.json` (`id`, `title`, `sub`, `lang`, `date`) и поменять `latest` на новый `id`.
3. Закоммитить в `main` — GitHub Pages обновит сайт сам.

Прогресс хранится в браузере (`localStorage`): статистика по словам общая для всех наборов (`espanol-stats`), незаконченные тренировки и ошибки — по наборам.
